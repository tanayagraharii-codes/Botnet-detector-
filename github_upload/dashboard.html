    About this tool

    The detector is a Random Forest classifier trained on the CTU-13 botnet dataset. The trained model is exported from Python and executed directly in this page: every score is computed locally by evaluating all 100 decision trees, and matches the output of the Python model.

    Live analysis passes flows through the model one at a time. By default it replays 400 labelled flows from the held-out test set, which the model never saw during training. You can instead load your own CSV of flow records; it is parsed in the browser and never leaves this device.

    Flow inspector shows the verdict for any single flow, with the tree votes and the features that drove the decision. Values can be edited to test what-if scenarios.

    Input format

    Export flows with CICFlowMeter. Both the Java column names (Flow Duration) and the Python ones (flow_duration) are recognised. Durations and inter-arrival times are expected in microseconds. The file must contain these 20 features:

    Optional columns: Label (0 = normal, 1 = botnet) enables accuracy checks, and Src IP, Dst IP and port columns are shown next to each flow.

    Limitations. CTU-13 was captured on a single university network in 2011. Present-day traffic differs substantially, so expect false positives and treat results as indicative rather than as a security verdict. Retrain on recent labelled traffic before relying on the model.
